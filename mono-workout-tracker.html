How Mono Lift works

A logbook built around one question: is it time to add weight?

The add-weight cue

This is the whole point of the tool. An exercise shows ↑ ADD WEIGHT when, in your last session, every set reached the top of its target rep range and none of them was logged at RIR 0 (i.e. you didn't grind to failure to get there). Hit the top on some sets but not all, and you'll see ALMOST — stay at this weight one more session.

RIR — reps in reserve

Optional, but it makes the cue smarter. Log how many reps you could still have done: leave 1–2 reps in reserve on working sets. RIR 0 means you went to failure. Leave the field blank if you'd rather not think about it — the cue still works off reps alone.

Target rep ranges

Main compounds default to 6–8, accessories to 8–12. Both are editable per exercise in Settings → Edit program, along with day names and exercise order.

Estimated 1RM

Each lift's detail shows an estimated one-rep max using the Epley formula (weight × (1 + reps/30)). It's a rough comparison tool across different rep counts — not a number to go test.

Rest days are the plan

Wednesday is cardio and joints; weekends are off. Nothing here tracks streaks or scolds you for a day away — recovery is when the work actually lands.

Sync

Same shared login as the rest of the toolkit — set it once in the Tool Center and this app picks it up. It writes data/mono-workout.json. A half-finished session is kept on this device only and never synced.

Edit program

Rename days, reorder or remove exercises, and set each target rep range (like 6-8). History follows the exercise, so renaming is safe.
